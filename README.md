# Harbor Elementary School — Air Quality Dataset

## Data Release Status

**✅ Released (v1.0)**

This repository contains the curated hourly air-quality measurements collected at the Harbor Elementary School monitoring station, together with the quality-control pipeline and the data dictionary. The dataset is distributed under the CC BY 4.0 licence.

## Site Information

- **Site**: Harbor Elementary School
- **Site type**: school
- **Address**: 2150 Harbor Blvd, Costa Mesa, CA 92627
- **Monitoring since**: 2024-03-12

## Contents

- `data/` — curated hourly measurements
- `notebooks/` — quality control and analysis notebooks
- `src/` — loading and QC utilities
- `results/` — summary tables and figures
- `docs/` — data dictionary and calibration notes
